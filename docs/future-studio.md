# Future Studio visual preview

The lightweight third direction is available at `/future-studio.html`. Design 01 and the minimal Atelier version remain available, with comparison links between the three pages.

This is a standalone visual exploration with its own HTML, CSS and JavaScript. It does not load the shopping application, approval API, wallet, checkout or payment scripts. It makes no orders, uploads, courier requests or storage writes. External font loading is the only additional external resource used by this page.

## Interactions

- Switch between the Tote and Mini concepts.
- Select sage, denim or copper fabric moods.
- Add up to three alphabetic initials; they are displayed as text and are not saved.
- Move the fabric-to-bag slider or replay the transformation.
- Drag horizontally to tilt the concept; keyboard Left/Right and Home provide tilt/reset controls.
- Follow comparison links or open the Atelier's fuller design prototype.

The bag is an SVG illustration transformed with CSS perspective, not a true rotatable 3D model, manufactured sample, exact material simulation or engineering preview. The page labels it as a concept. Predefined fabric moods do not restore the paused reference-photo feature.

The animation honors reduced-motion preferences on page load. Under that preference the page begins in the completed bag state, replay leaves that state still, and the range remains available for manual exploration. Animation runs only for a short transformation rather than a perpetual rendering loop. Vertical touch scrolling remains available in the illustration area.

The main-page pricing and checkout behavior of the existing versions is untouched by this preview. Actual courier rates and the Meerut origin PIN are still unconfigured in the fuller prototype.
